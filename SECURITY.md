# Security Policy

Please report security issues privately to the repository maintainer rather than opening a public issue containing exploit details or secrets.

## Scope
Security-sensitive areas include:
- installer path validation;
- global instruction composition/restore;
- rollout JSONL parsing;
- routed worker sandbox settings;
- command construction;
- project discovery.

Do not include API keys, auth files, session tokens, or private repository content in reports.
